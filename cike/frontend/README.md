# 此刻 cike

轻量化图文分享社区「此刻」的前端实现（V1.0 纯前端演示版，数据走本地 mock + localStorage）。

## 技术栈

- Vue 3（组合式 API）+ Vite
- Element Plus + @element-plus/icons-vue
- Vue Router（路由 + 登录守卫）
- Pinia（用户态 / 互动数据管理）

## 功能页面

| 页面 | 路由 | 说明 |
| --- | --- | --- |
| 登录注册 | `/login` | 手机号 + 密码 / 验证码登录注册，表单校验、60s 倒计时、登录态持久化 |
| 首页 | `/` | 分类标签、关键词搜索、瀑布流笔记卡片、滚动触底加载 |
| 发布页 | `/publish` | 多图上传预览、拖拽排序、话题选择、公开/私密、草稿自动保存（需登录） |
| 详情页 | `/note/:id` | 多图切换、点赞/收藏/关注、评论与回复、作者可删除、相关推荐 |
| 个人中心 | `/profile` | 资料编辑、作品/收藏/点赞三个 tab、作品可见性与删除、退出登录（需登录） |

## 三端自适应

按 PRD 断点实现差异化布局：

- 移动端（≤768px）：单列堆叠 + 底部固定 tab 导航
- 平板端（769–1200px）：三列瀑布流、局部左右分栏
- 电脑端（≥1201px）：左侧固定导航栏、发布页/详情页/个人中心左右分栏、四列瀑布流

## 演示账号

任意手机号即可登录；验证码固定为 `123456`。

## 本地运行

```bash
npm install
npm run dev
```
